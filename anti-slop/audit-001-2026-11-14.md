# Audit Antislop 001: BMS MENARA PERTIWI

**Tanggal:** 14 November 2026
**Mode:** AFTER (audit UI yang sudah jadi, belum ada perubahan)
**Cakupan:** seluruh UI di `src/index.js` (template `ui` baris 57-401: HTML baris 120, CSS baris 58-119, skrip klien baris 130-400)
**Metode:** inspeksi statis kode. Tidak ada browser di perangkat ini (`wrangler dev --local` gagal), jadi temuan dikumpulkan dari markup, CSS, dan handler, bukan dari pengukuran visual. Rasio kontras dihitung dengan rumus WCAG. Ukuran tap target dihitung dari box model CSS.

**Prioritas mengikuti tingkat aturan:** Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

|---|---|---|
| HIGH (Hard Gate) | 14 | 1-14 |
| MEDIUM (Purpose-Gate) | 5 | 15-19 |
| LOW (Quality Locks) | 5 | 20-24 |

Balas dengan nomor yang ingin diperbaiki (contoh: "perbaiki 1, 3, 6"). Nomor yang tidak disebut tidak akan disentuh.

## HIGH: Hard Gate

### 1. Label formulir tidak terhubung ke input
**Aturan:** R-39
**Lokasi:** `src/index.js:120`
**Bukti:** 42 elemen `<label>`, 0 memakai `for=`, 0 membungkus kontrol. 28 kontrol (input/select) punya label secara visual tetapi tidak secara program, dan 14 `<label>` dipakai sebagai judul kartu/legenda tanpa kontrol ("Progres Pengisian Hari Ini", "Tren Pengisian", "Sudah Diisi", dst).
**Alasan:** pembaca layar tidak bisa menyebutkan nama field, dan `<label>` tanpa kontrol bukan judul yang sah.
**Perbaikan:** beri `id` pada setiap kontrol dan `for` pada labelnya; ganti 14 label dekoratif menjadi `<span>`/`<h3>`.

### 2. Struktur dokumen tidak lengkap
**Aturan:** R-39
**Lokasi:** `src/index.js:120`
**Bukti:** 0 `<h1>`, 16 `<h2>`, 0 `<h3>`, 0 `<footer>`, 1 `<main id="app">` yang justru `hidden` saat belum login. Form login ada di `<section id="login">` di luar `<main>`.
**Alasan:** tidak ada judul utama, tidak ada landmark footer, dan saat login satu-satunya konten berada di luar landmark main.
**Perbaikan:** satu `<h1>` (nama aplikasi), subjudul menjadi `<h2>`/`<h3>` berurutan, pindahkan login ke dalam `<main>`, tambahkan `<footer>` kecil (versi/jam sinkron).

### 3. `div` dan `canvas` tanpa peran dan nama aksesibel
**Aturan:** R-39
**Lokasi:** `src/index.js:120`
**Bukti:** 4 kartu `<div class="kpi ..." style="cursor:pointer" onclick="kpiClick(...)">` tanpa `role`, `tabindex`, atau `aria-label`. 3 `<canvas id="cStatus|cKind|cTrend">` tanpa `role="img"`, `aria-label`, atau teks fallback; dua grafik punya `onClick` filter.
**Alasan:** kontrol yang bisa diklik tidak diumumkan sebagai kontrol, dan grafik tidak punya nama atau isi alternatif.
**Perbaikan:** jadikan kartu KPI `<button>`; beri canvas `role="img"` + `aria-label` ringkas dan sediakan tabel ringkas sebagai alternatif.

### 4. Navigasi keyboard tidak lengkap
**Aturan:** R-32
**Lokasi:** `src/index.js:132-133`
**Bukti:** `enableCollapse()` memasang `h2.onclick` pada 4 bagian di tab Pengaturan, dan 4 kartu KPI hanya punya `onclick`. Keduanya tidak bisa difokus atau diaktifkan dengan Enter/Space. Filter grafik juga hanya lewat klik canvas.
**Alasan:** pengguna keyboard tidak bisa membuka bagian pengaturan, membuka rincian KPI, atau memfilter grafik.
**Perbaikan:** ubah pemicu menjadi `<button>` asli (atau tambahkan `role="button"`, `tabindex="0"`, dan handler Enter/Space); sediakan filter alternatif berupa tombol/select.

### 5. `cursor: pointer` hampir tidak diterapkan
**Aturan:** R-39
**Lokasi:** `src/index.js:84-108`
**Bukti:** hanya 3 aturan CSS (`.tech-side button`, `.admin-home button`, `.collapse-head`) plus 4 inline pada kartu KPI. Tombol lain (Bootstrap `.btn` tidak lagi mengatur cursor di v5) tampil dengan panah biasa, begitu juga `select` dan tombol aksi tabel.
**Alasan:** affordance klik hilang pada mayoritas kontrol, padahal aturannya wajib untuk semua elemen interaktif aktif.
**Perbaikan:** satu aturan dasar `button, select, [role="button"] { cursor: pointer }` dan `:disabled { cursor: not-allowed }`.

### 6. Kontras label sidebar gagal WCAG AA
**Aturan:** R-25
**Lokasi:** `src/index.js:88`, `108`
**Bukti:** `.side-label` memakai `#7fa8c0` di atas gradien `#0b2239` ke `#145b78`, ukuran 11-12px. Rasio 2.95:1 di ujung terang (batas minimum 4.5:1). Ujung gelap 6.35:1, jadi teks gagal hanya di sebagian area.
**Alasan:** label "Shift", "Checklist", "Lainnya", "Monitoring" sulit dibaca, dan aturan mewajibkan uji di seluruh area yang dilalui teks.
**Perbaikan:** naikkan ke `#a9c6d8` atau lebih terang (target minimal 4.5:1 di ujung terang).

### 7. Em dash di teks UI
**Aturan:** R-02
**Lokasi:** `src/index.js:120` (2 kali), `138`, `188`
**Bukti:** 4 karakter em dash (U+2014): keterangan dashboard ("... memfilter data ... hasil filter ..."), placeholder KPI, sapaan `"Halo, " + me.name + " ... "`, dan sel tabel user tanpa aksi.
**Alasan:** em dash dilarang di teks yang ditulis agen; penggantinya titik, koma, titik dua, atau tanda kurung.
**Perbaikan:** ganti dengan titik/koma; placeholder KPI memakai `0` atau teks "Belum ada data".

### 8. Tidak ada state loading, error lewat `alert()`
**Aturan:** R-27
**Lokasi:** `src/index.js:130-400`
**Bukti:** 0 penanda loading ("Memuat"/spinner), 17 `alert()` dan 3 `confirm()` untuk error/konfirmasi. Sebelum data masuk, DOM sudah menampilkan `0`, `0%`, placeholder tanda pisah, dan "dari 0 teknisi" seolah angka nyata. `#loginMsg`, `#saveMsg`, `#myHistMsg` tidak punya `aria-live`.
**Alasan:** pengguna tidak tahu data sedang dimuat, melihat angka palsu sesaat, dan pesan status tidak diumumkan ke pembaca layar.
**Perbaikan:** tambahkan skeleton/`aria-busy` saat fetch, state kosong yang eksplisit, dan error inline di dekat kontrol (bukan `alert`); beri `role="status"` pada pesan.

### 9. Tombol "Kembali ke Menu" tidak berfungsi
**Aturan:** R-26
**Lokasi:** `src/index.js:120`
**Bukti:** `<button id="adminBack" class="btn btn-outline-secondary">← Kembali ke Menu</button>` tidak punya `onclick`, tidak ada `$("adminBack")`, dan tidak termasuk handler `querySelectorAll`. Pencarian `adminBack` di seluruh file hanya menemukan CSS `#adminBackBar`, markup, dan `adminTab()` yang menyembunyikan/menampilkan bar-nya.
**Alasan:** kontrol mati, diklik tidak terjadi apa pun.
**Perbaikan:** pasang `$("adminBack").onclick = () => adminTab()`.

### 10. Tap target di bawah 44px
**Aturan:** R-03
**Lokasi:** `src/index.js:120` dan CSS Bootstrap hasil `bsApply`
**Bukti:** `.btn`/`.form-control`/`.form-select` Bootstrap: 24px baris + 12px padding + 2px border ≈ 38px. Tombol `r7`/`r14`/`r30` dengan inline `padding:4px 10px` ≈ 34px. `.tech-side button` mode sidebar (font 15px) ≈ 38px. `.tech-side select` ≈ 37px.
**Alasan:** kontrol terlalu kecil untuk jempol, terutama tombol aksi tabel dan pemilih rentang tren.
**Perbaikan:** naikkan padding/tinggi minimum ke 44px pada breakpoint sentuh.

### 11. Logo tanpa dimensi intrinsik
**Aturan:** R-40
**Lokasi:** `src/index.js:120`, `62-63`
**Bukti:** `<img src="/logo.png" alt="Logo Menara Pertiwi">` tanpa `width`/`height`/`aspect-ratio`; ukuran hanya dari CSS (`height:36px`, `26px` di bawah 520px).
**Alasan:** ruang gambar belum dipesan sebelum file selesai dimuat, memicu pergeseran layout.
**Perbaikan:** tambahkan `width`/`height` asli logo (atau `aspect-ratio`).

### 12. Chart.js memblokir render
**Aturan:** R-40
**Lokasi:** `src/index.js:57`
**Bukti:** `<script src="https://cdn.jsdelivr.net/npm/chart.js@4.4.1/dist/chart.umd.min.js"></script>` di `<head>` tanpa `defer`/`async`; hanya dipakai di dashboard admin.
**Alasan:** skrip pihak ketiga yang render-blocking menahan tampilan awal untuk semua pengguna, termasuk teknisi yang tidak membuka grafik.
**Perbaikan:** `defer`, atau muat saat tab Ringkasan dibuka (pola yang sudah dipakai ExcelJS).

### 13. Tidak ada arah desain tertulis
**Aturan:** R-37
**Lokasi:** akar repo
**Bukti:** tidak ada `DESIGN.md` atau panduan merek. Tidak ada catatan alasan untuk gradien navy-teal, 5 deklarasi shadow, 7 nilai radius, atau campuran Bootstrap.
**Alasan:** tanpa arah, setiap keputusan visual tidak bisa diuji dan UI jatuh ke default netral; aturan mewajibkan arah atau label "draft tanpa arah".
**Perbaikan:** tulis `DESIGN.md` singkat (palet, tipografi, radius, elevasi, komponen) atau nyatakan UI ini draft.

### 14. Data uji palsu tampil sebagai data operasional
**Aturan:** R-17
**Lokasi:** D1 produksi, `d1-dump/cleanup-fake-data.sql`
**Bukti:** 249 checklist palsu (16 Okt sampai 14 Nov 2026) kini muncul di Dashboard, Rekap Bulanan, dan ekspor Excel sebagai catatan nyata.
**Alasan:** angka tanpa sumber nyata dilarang; data ini dibuat atas permintaan untuk pengujian, jadi harus dicabut sebelum dipakai operasional.
**Perbaikan:** jalankan `wrangler d1 execute daily-checklist-db --remote --file=d1-dump/cleanup-fake-data.sql`, atau tandai jelas sebagai data uji di UI.

## MEDIUM: Purpose-Gate

### 15. Emoji sebagai sistem ikon
**Aturan:** R-04
**Lokasi:** `src/index.js:120`, `138`
**Bukti:** 14 emoji unik, ±23 pemakaian: ❄️ ⚡ 🚰 🗂️ 🔒 👋 📊 📝 📅 ⚙️ 🌅 ☀️ 🌙 ✔️. Sepuluh di antaranya generik atau dekoratif (📊 📝 📅 ⚙️ 👋 🌅 ☀️ 🌙 ✔️).
**Alasan:** emoji bukan ikon yang relevan dan ditulis sebagai alasan; tampilannya berbeda di tiap OS dan beberapa tidak membawa informasi.
**Perbaikan:** pertahankan hanya yang benar-benar informatif, sisanya hapus atau ganti SVG inline sederhana.

### 16. Shadow dipakai di hampir semua permukaan
**Aturan:** R-12
**Lokasi:** `src/index.js:60-62`, `66`, `84`, `105`
**Bukti:** 5 deklarasi `box-shadow` mengenai header, badge logo, setiap `.panel`, `.tech-side`, dan `.admin-home`.
**Alasan:** shadow kehilangan fungsi elevasi ketika semua elemen mengambang; tidak ada alasan elevasi tertulis.
**Perbaikan:** sisakan shadow hanya untuk elemen yang memang di atas konten (header sticky, modal), panel datar memakai border.

### 17. Gradien yang sama di tiga permukaan
**Aturan:** R-01
**Lokasi:** `src/index.js:60`, `84`, `105`
**Bukti:** `linear-gradient(115deg,#0b2239,#145b78)` pada header, `linear-gradient(170deg,...)` pada sidebar teknisi dan kartu menu admin.
**Alasan:** gradien boleh bila bagian identitas merek, tetapi alasannya belum ditulis dan pengulangannya di tiga area membuat hierarki rata.
**Perbaikan:** konfirmasi apakah ini identitas merek. Bila ya, catat di `DESIGN.md` dan pakai di satu level hierarki saja.

### 18. Font Inter dideklarasikan tetapi tidak pernah dimuat
**Aturan:** R-06
**Lokasi:** `src/index.js:58`, `88`, `108`
**Bukti:** `font-family:Inter,system-ui,Arial` tanpa `<link>` Google Fonts atau `@font-face`, sehingga yang tampil selalu system-ui/Arial. Ditambah label uppercase 11-12px dengan tracking 0.6-1.2px.
**Alasan:** tipografi tidak sesuai niat kode, dan uppercase ber-tracking lebar adalah pola yang disebut langsung di R-06.
**Perbaikan:** muat Inter (atau hapus dari daftar), dan turunkan tracking label ke 0.2-0.4px.

### 19. Motion tanpa `prefers-reduced-motion`
**Aturan:** R-19
**Lokasi:** `src/index.js:151`, `81`
**Bukti:** `scrollIntoView({behavior:"smooth"})`, `transition:width .4s` pada bar KPI, dan transisi Bootstrap. Tidak ada satu pun aturan `prefers-reduced-motion`.
**Alasan:** gerakan tidak punya alasan UX tertulis dan tidak bisa dimatikan pengguna yang sensitif terhadap animasi.
**Perbaikan:** tambahkan blok `@media (prefers-reduced-motion: reduce)` yang mematikan smooth scroll dan transisi.

## LOW: Quality Locks

### 20. Dua sistem visual bercampur
**Aturan:** R-20
**Lokasi:** `src/index.js:135`
**Bukti:** `bsApply()` plus `MutationObserver` menambahkan kelas Bootstrap ke setiap `button`, `table`, `input`, `select`, dan `textarea` saat runtime. Hasilnya separuh UI memakai palet navy-teal kustom, separuh memakai default Bootstrap (biru `#0d6efd`, radius 6px, font sistem).
**Alasan:** identitas visual jadi tidak konsisten dan sulit diprediksi; dua sistem harus dirawat sekaligus.
**Perbaikan:** pilih satu sistem. Bila Bootstrap dipakai, override variabelnya ke palet merek; bila tidak, hapus `bsApply`.

### 21. Tujuh nilai radius tanpa aturan
**Aturan:** R-11
**Lokasi:** `src/index.js:58-119`
**Bukti:** 8, 10, 12, 14, 16, 20, 22px pada CSS kustom, ditambah 6px dari Bootstrap.
**Alasan:** variasi radius seharusnya menandai hierarki, bukan acak per komponen.
**Perbaikan:** tetapkan 3 tingkat (mis. 8px kontrol, 12px kartu, 20px panel besar).

### 22. Palet melebihi batas 3 warna inti + 1 aksen
**Aturan:** R-29
**Lokasi:** `src/index.js:58-119`
**Bukti:** 33 nilai hex di CSS: navy `#0b2239`, teal `#145b78`, aksen `#146c94`, tiga warna status masing-masing dua shade (`#12b76a`/`#067647`, `#f79009`/`#b54708`, `#f04438`/`#b42318`), plus palet Bootstrap (biru, hijau, merah).
**Alasan:** terlalu banyak warna aktif tanpa sistem yang menjelaskan perannya.
**Perbaikan:** kunci 1 aksen dan 3 warna status, turunkan shade ganda menjadi satu per status.

### 23. Empat blok dashboard mengulang angka yang sama
**Aturan:** R-05
**Lokasi:** `src/index.js:120`
**Bukti:** "Dashboard Admin" (KPI + grafik), "Dashboard Operasional" (Sudah Diisi/Tindak Lanjut/Belum + persentase), dan "Dashboard Manajemen" menampilkan metrik yang sama tiga kali; istilah "dashboard" muncul empat kali.
**Alasan:** struktur halaman mengulang isi alih-alih menyusun satu hierarki.
**Perbaikan:** satu blok ringkasan utama, sisanya menjadi rincian yang bisa dibuka.

### 24. Strategi tema tidak ditulis
**Aturan:** R-21
**Lokasi:** `src/index.js:58`, `84`, `105`
**Bukti:** tema terang tetap dengan panel navy gelap di dalamnya, tanpa alasan tertulis dan tanpa toggle.
**Alasan:** aturan meminta alasan kuat untuk tema tetap; saat ini campuran terang/gelap tidak dijelaskan.
**Perbaikan:** catat alasannya di `DESIGN.md`, atau sediakan toggle yang benar-benar berfungsi di kedua mode.

## Yang sudah lolos (tidak perlu diperbaiki)

- R-02 (selain em dash): tidak ada en dash, tanda kutip keriting, atau buzzword R-16.
- R-15: CTA spesifik ("Tampilkan Riwayat Saya", "Unduh Excel (.xlsx)", "Ekspor PDF / Cetak"), bukan "Get Started".
- R-17/R-18/R-36: tidak ada testimoni, klaim keamanan, atau statistik karangan di UI (data uji pada temuan 14 adalah fixture, bukan klaim).
- R-24: semua item navigasi menuju panel yang benar-benar ada.
- R-27 (sebagian): empty state teks sudah ada ("Belum ada checklist terisi", "Klik Tampilkan Riwayat Saya").
- R-39 (sebagian): `<html lang="id">`, `<title>` unik, viewport tanpa `user-scalable=no`, logo punya `alt`, tidak ada `outline: none`.
- R-40 (sebagian): ExcelJS dimuat lazy dengan SRI; grafik memakai kontainer tinggi tetap sehingga ruangnya sudah dipesan.
- Layout: tidak ada `100vh`, tabel dibungkus `.scroll{overflow:auto}`, grid memakai `auto-fit/minmax`, dan ada 3 breakpoint (520/600/860px).
