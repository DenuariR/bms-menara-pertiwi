# Audit 002: bug fungsional dan tema biru muda

Tanggal: 2026-11-15
Lingkup: seluruh alur admin dan teknisi pada `src/index.js`, ditambah palet warna.
Metode: pembacaan kode, uji jsdom, validator statis, dan uji langsung ke Worker produksi.

## Temuan dan perbaikan

| No | Temuan | Perbaikan |
| --- | --- | --- |
| 1 | Login peka huruf besar. `admin` gagal, `Admin` berhasil. | Username di-trim dan dicocokkan dengan `lower(username)=lower(?)` di server. Uji `admin`, `Admin`, dan ` admin ` semuanya 200. |
| 2 | Pemeriksaan username ganda peka huruf besar. | Cek ganda memakai `lower(username)` sebelum hash dan insert. |
| 3 | Pembuatan user tidak memvalidasi panjang nama, pola username, atau panjang password di server. | Nama maks. 100, username 3-64 karakter `[A-Za-z0-9._-]`, password 8-128. Nilai di-trim. |
| 4 | Jam shift `99:99` diterima. | Validasi `00:00` sampai `23:59`, nama maks. 60, dan jam mulai tidak sama dengan jam selesai. |
| 5 | Nama shift beda huruf besar dapat membuat duplikat. | Cek `lower(name)` dan balas 409 bila bentrok. |
| 6 | Hapus shift yang masih dipakai checklist atau riwayat berakhir 500 karena foreign key. | Cek referensi checklist, riwayat, jadwal, dan akun. Balas 409 dengan pesan yang jelas. |
| 7 | Tanggal checklist `2026-99-99` lolos regex. | Validasi tanggal kalender nyata. Tanggal pada roster juga memakai validator yang sama. |
| 8 | `values:null` atau array pada checklist memicu 500. | Body wajib objek, `values` wajib objek bukan array. |
| 9 | Body JSON rusak pada endpoint POST berakhir 500. | Helper `readBody`, balas 400 `Body JSON tidak valid`. |
| 10 | `label` item non-string memicu 500 karena `.trim()`. | Cek `typeof label === "string"` lalu trim. |
| 11 | Roster menerima user id yang tidak ada lalu gagal foreign key. | Id disaring ke user role `user` yang benar-benar ada. |
| 12 | Roster dengan tanggal tidak valid memicu 500 di `toISOString`. | Validasi tanggal kalender. |
| 13 | Readout "Belum Diisi" per jenis memakai jumlah teknisi, bukan 3 sesi per teknisi. | Menjadi `techCount*3 - records`. |
| 14 | Donut "Belum diisi" memakai jumlah teknisi, tidak sebanding dengan segmen record lain. | Menjadi `techCount*3 - total record`. |
| 15 | Kartu kondisi peralatan memakai `tech - records` dan teks "teknisi belum mengisi". | Menjadi `tech*3 - records` dengan jumlah teknisi yang belum lengkap. |
| 16 | Tanggal di Ringkasan tidak menyegarkan kondisi peralatan dan tren. | `#dashDate` memanggil ulang ringkasan dan insight. |
| 17 | Logout tidak mematikan timer segarkan otomatis. | Timer dibersihkan, pilihan otomatis dikembalikan ke Nonaktif, password dikosongkan. |
| 18 | Hapus shift tanpa `catch` menghasilkan promise rejection. | Dibungkus `try/catch` dan memakai notifikasi galat. |
| 19 | Tombol Enter di kolom login tidak melakukan apa pun. | Handler Enter memanggil login, tombol dinonaktifkan saat memeriksa. |
| 20 | Tombol "Lihat" rincian menyisipkan JSON ke atribut `onclick`. Nilai berisi entitas HTML dapat menjadi stored XSS. | Nilai disimpan di cache dan tombol memakai `data-detail`, bukan `onclick` berisi data. |
| 21 | Nama teknisi dengan apostrof merusak atribut `data-name` di matriks. | Apostrof di-encode menjadi `%27`. |
| 22 | Daftar item checklist kosong sampai jenis monitoring diganti. | `loadItems()` dipanggil saat admin masuk. |
| 23 | Ekspor bulanan memakai cache bulan lama bila bulan diganti tanpa menekan Tampilkan. | Ekspor memuat ulang rekap bulan aktif lebih dulu. |
| 24 | Setelah edit checklist, status dan catatan lama tertinggal di formulir. | `exitEdit` mengembalikan status ke "Sudah Diisi" dan mengosongkan catatan. |
| 25 | Tombol simpan bisa ditekan dua kali saat request berjalan. | Tombol dinonaktifkan selama request dan aktif lagi di kedua jalur. |
| 26 | Perubahan tanggal pada formulir teknisi tidak menyegarkan status shift di sidebar. | `#date` memanggil `loadShiftStatus`. |
| 27 | Tren dan grafik harian menghitung record bertanggal masa depan. | Query dibatasi sampai `wibToday()`. |
| 28 | Perhitungan bulan berjalan pada tren memakai zona waktu server. | Bulan dan hari dihitung dari `wibToday()`. |
| 29 | Galat API pada pemuatan awal menghasilkan unhandled rejection. | Semua pemanggil dashboard memakai `reloadAdmin()` dengan `catch`. |
| 30 | Sesi kedaluwarsa hanya menampilkan galat tanpa kembali ke halaman login. | `api()` menangani 401, logout, dan menampilkan pesan sesi berakhir. |

## Batas pengujian

- Tidak ada peramban visual di perangkat ini. Pemeriksaan tampilan memakai jsdom, analisis CSS, dan perhitungan kontras, bukan tangkapan layar.
- Password akun teknisi bawaan tidak diketahui, sehingga alur teknisi di produksi diuji lewat akun sementara yang langsung dihapus.
- Jalur destruktif pada data nyata (hapus checklist, hapus shift yang dipakai) tidak dijalankan. Perlindungannya diverifikasi lewat kode dan respons validasi.
